# Security Policy

## Supported versions

| Version | Supported |
| --- | --- |
| `22.x` | :white_check_mark: Active |
| `21.x` | :white_check_mark: Maintenance (fixes only) |
| `< 21` | :x: Unsupported |

## Reporting a vulnerability

Please report security vulnerabilities **privately** to **zmiguel96@gmail.com**. Do not open a public issue.

We will acknowledge your report within 48 hours and aim to publish a fix as soon as possible. Please include enough detail to reproduce the issue, and avoid including sensitive data.
